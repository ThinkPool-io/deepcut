How it works

Open-source engines underneath

The prototype runs fully in your browser. The production stack swaps in proven open-source audio tools.

Listen BPM + key live

Tempo by onset autocorrelation and key by chroma profile run in the browser today. Production adds beat grids, downbeats and section detection.

  • Essentia for key, BPM and embeddings
  • madmom for beats and downbeats
  • librosa for structure segmentation

Match next

Audio embeddings go into a vector index, so "sounds like" is a nearest-neighbour query re-ranked by key, tempo and energy.

  • Qdrant as the vector database
  • Tone.js for previews and the blueprint player

Build MIDI packs live

Blueprints export Standard MIDI today. Next come native project files and your-own-audio tools.

  • Basic Pitch: your audio to MIDI
  • Demucs: stems from your own tracks
  • Surge XT and Vital presets in every pack
